从零自学 AI Agent 的学习笔记：目标是做出能帮机械 / 工程软件干活的 Agent。

开始于 2026 年 11 月 14 日（星期六）· 每天 30–60 分钟，累了就 10 分钟保底 · 周日休息 · 错过不补

怎么用这个仓库

每天一个文件夹：days/day-001-2026-11-14/ 这样的名字里就带了日期。每天只做当天那一页里的事，做完就算完成，不用一次追好几天的进度。

打开方式：直接用浏览器打开 index.html，或者在 GitHub 上点开对应文件夹里的 index.html 看渲染效果。所有页面都是纯静态的，不用装任何东西，也不用联网。

六个阶段

进行中阶段 0 · 捡回 Python 和命令行手感

目标：能读懂一段短短的 Python 代码，知道每一行在干什么，并能在命令行里把它跑起来。不是要背语法，是要建立“我能看懂、能改一小段”的手感。

未开始阶段 1 · 亲手调通一次大模型 API

目标：自己写一段代码，把一句话发给大模型，再把回答打印出来。弄明白 API 地址、密钥、输入、输出这四个东西分别放在哪里。

未开始阶段 2 · 手写工具调用和 Agent 循环（先不用框架）

目标：不靠任何框架，自己写出“想一想 → 决定用什么工具 → 执行 → 看结果 → 再想一想”这个循环。理解了这个，再看任何 Agent 框架都知道它在干什么。

未开始阶段 3 · Git 五条命令 + 读报错 + 防屎山手艺

目标：只记五条最常用的 Git 命令；报错先看最后一行，再决定怎么办；每次只改一小步、随时能回滚，不再攒出屎山代码。

未开始阶段 4 · 补 SolidWorks 操作与 API，让迷你 Agent 驱动建模

目标：先把 SolidWorks 的基本操作补到和 CAXA 差不多的水平，再让一个迷你 Agent 通过 API 驱动它做一次简单建模。

未开始阶段 5 · 长期目标：内置 MCP / skill 的工程 Agent 框架

目标：做一个专门为工程软件准备的 Agent 框架，常用的 MCP 和 skill 内置好，不用用户自己一个个装，并朝着更懂工程问题的方向慢慢打磨。

第 1 天 · Python 从零开始

2026 年 11 月 14 日 · 星期六 · 第 1 天 · 阶段 0

标准版 30–60 分钟 · 保底版 10 分钟（只做“保底任务”那一节）

今天要达到什么

做完今天，你要能做到三件事：第一，读一段只有十几行的 Python 代码，能逐行说出每一行在干什么；第二，知道怎么在命令行里把它跑起来；第三，报错了知道先看哪里。

不用背语法，不用一次全记住。目标是“看得懂”，不是“写得出长篇大论”。以后 Agent 写出来的代码，你就是用今天这套本事去看它的。

1 · Python 在 Agent 的活里是干什么的

可以把 Python 想成 Agent 的“手”。大模型是脑子，只会动嘴；真正要发请求、读写文件、调 SolidWorks 的接口、循环跑很多次，靠的都是外面这层 Python 代码。

你以前学过 C++，对比着记最省事：

  • C++ 要先声明类型、写分号、用大括号；Python 不用，大部分时候直接写就行。
  • C++ 写十行才能做的事，Python 常常三五行就够了。
  • Python 自带和现成的库特别多，调大模型 API、读文件、处理文字，都有人写好的轮子。

所以学 Agent 不用先把 Python 学成专家，学到“能读懂 Agent 循环里那几十行”就够用了，后面用到什么再补什么。

2 · 第一行代码：print 和变量

print("你好，Agent")
# print 就是“把括号里的东西显示出来”

name = "小肥鱼"
print(name)
print("你好，" + name)

三点注意：

  • print(...)：括号里放什么，就显示什么。引号里的叫字符串，就是一串文字。
  • name = "小肥鱼"：这叫变量，给一段数据起个名字，之后用名字就能找到它。Python 不用提前声明它是什么类型，直接 = 就行。
  • "你好，" + name：字符串之间用 + 可以拼起来，结果是 你好，小肥鱼。

数字也一样，变量里可以放数字，而且数字能直接算：

age = 19
print(age + 1)   # 显示 20

3 · input：让程序等你输入一句话

name = input("你叫什么名字？")
print("你好，" + name)

input(...) 会先显示括号里的提示，然后停下来等你打字、按回车，你打的内容就存进 name 这个变量。Agent 里很多“等用户说一句话”的地方，道理和这个是一样的。

容易错：input 拿到的永远是文字。哪怕你输入的是 19，它也是文字 "19"，不能直接拿去做加减。要算数，得先转成数字：int("19") 变成数字 19。

4 · if 判断：程序开始“做决定”

age = 19

if age >= 18:
    print("成年了")
else:
    print("未成年")

这段话翻译成中文就是：如果 age 大于等于 18，显示“成年了”，否则显示“未成年”。

和 C++ 对比着记，只有一处最容易错：Python 没有大括号，靠缩进表示“哪些行属于这个 if”。冒号 : 后面、缩进四个空格的那一行，就是条件成立时才执行的。缩进一乱，程序的意思就变了，运行时还会直接报错。

记一个口诀：看到冒号就换行缩进；回到和 if 对齐的位置，就表示“这个判断结束了”。

5 · 循环：让电脑替你重复

Agent 干活经常要重复：一条一条处理、一遍一遍重试。循环就是干这个的。

for i in range(3):
    print(i)

# 显示：
# 0
# 1
# 2

range(3) 的意思是“0、1、2 这三个数”，所以循环跑三遍。注意它是从 0 开始的，不是 1。

count = 0
while count < 3:
    print("第", count + 1, "次")
    count = count + 1

while 是“只要条件还成立，就一直跑”。上面这段同样跑三遍，但 count = count + 1 这一行不能漏——漏了条件永远成立，程序就停不下来了。这也是 Agent 里“循环停不下来”最常见的原因之一。

6 · 怎么在命令行里跑一个 .py 文件

把上面的代码存成一个文件，比如 hello.py（本页同目录里已经有一份，可以直接拿去跑）。然后：

cd 文件所在的文件夹
python hello.py

如果你的电脑上 python 不认，试试 python3 hello.py。看到输出就说明跑通了。

报错了先看最后一行。Python 的报错信息很长，但真正有用的往往是最后一两行：它会告诉你是哪一行、出了什么错（比如缩进不对、名字写错了、括号没关上）。先读最后一行，再把报错原样贴给 Agent，比直接说“跑不起来”管用得多。

测一测：读代码小题

下面四道题不用写代码，只要读，然后想一想会显示什么。点“显示答案”对一下。

第 1 题

print(1 + 2)
print("1" + "2")

这两行分别会显示什么？为什么不一样？

第一行显示 3，因为 1 和 2 是数字，+ 是加法。第二行显示 12，因为带引号的 "1" 和 "2" 是文字，+ 是拼接。同一符号，用在数字和文字上意思不一样。

第 2 题

name = "小肥鱼"
print("你好，" + name)

会显示什么？

显示 你好，小肥鱼。先把 "小肥鱼" 存进变量 name，再把它拼到 "你好，" 后面。

第 3 题

age = 16
if age >= 18:
    print("成年了")
else:
    print("未成年")

会显示什么？如果把 16 改成 20 呢？

显示 未成年，因为 16 不满足 >= 18，所以走 else 那一行。改成 20 就满足条件，显示 成年了。

第 4 题

for i in range(3):
    print(i)

会显示哪几个数字？一共显示几行？

显示 0、1、2，一共三行。range(3) 从 0 开始，到 2 结束。

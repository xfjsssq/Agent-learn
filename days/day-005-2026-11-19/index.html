第 5 天 · 命令行只记四件事

2026 年 11 月 19 日 · 星期四 · 第 5 天 · 阶段 0

标准版 30–60 分钟 · 保底版 10 分钟（只做“保底任务”那一节）

今天要达到什么

做完今天，你要能做到四件事：第一，用 cd 走进任何一个文件夹；第二，用 dir 看清楚当前文件夹里有什么；第三，用 python xxx.py 把一个 Python 文件跑起来；第四，程序卡住或者跑个没完的时候，用 Ctrl+C 把它停下来。

前四天你其实已经零零散散用过这些命令了：建虚拟环境要 cd 进文件夹，装包之前要确认自己在哪个文件夹，跑 hello.py、try_requests.py 用的就是 python xxx.py。今天就是把它们收拢成一张小抄，练熟了，以后不用每次都现查。这是阶段 0 的最后一块地基——命令行顺手了，阶段 1 调 API 才能专心想逻辑，而不是跟黑窗口较劲。

1 · 命令行是什么：一个黑窗口，一行命令

命令行就是一个黑底白字的窗口，你敲一行字、按回车，电脑就照着做一件事。它没有按钮和鼠标点来点去，但胜在直接：你想让电脑做什么，写出来就行。

Windows 上打开它的方法：按 Win + R，输入 cmd，按回车；或者在开始菜单里搜“命令提示符”。打开之后你会看到一行提示符，像这样：

C:\Users\你的名字>

这行字就是命令行的“当前所在位置”——你现在站在哪个文件夹里。所有命令都是在这个位置上执行的，文件找不找得到，全看你现在站在哪儿。这就是为什么第一件事是学会“走路”：进对文件夹。

PowerShell 也行：Windows 还有一个叫 PowerShell 的黑窗口，功能更强。今天这四条命令在 cmd 和 PowerShell 里都能用，哪个顺手用哪个，不用纠结选哪个。

2 · 第一件事：cd，进文件夹

cd 是 change directory 的缩写，意思是“换到这个文件夹去”。用法就是 cd 后面跟文件夹的名字：

cd agent-practice

敲完回车，提示符就变成 C:\Users\你的名字\agent-practice>，说明你已经走进 agent-practice 这个文件夹了。接下来你敲的所有命令，都是在这个文件夹里执行的。

常用的三个走法，记住就够了：

# 走进一个子文件夹：
cd agent-practice

# 回到上一级文件夹：
cd ..

# 直接跳到某个完整路径（从盘符写起）：
cd C:\Users\你的名字\agent-practice

cd .. 里的两个点就是“上一级”的意思。在 agent-practice 里敲 cd ..，就回到 C:\Users\你的名字。一层一层往上走，就靠它。

最容易翻车的一点：文件夹名字里有空格，比如 my project，直接 cd my project 会报错，因为命令行以为你要进两个地方。办法是加上双引号：cd "my project"。所以平时给文件夹起名字，尽量别用空格，用 - 或者 _ 连接，比如 agent-practice。

还有一个省事的技巧：敲文件夹名字的前几个字母，按一下 Tab 键，命令行会自动帮你补全剩下的部分。按一下不对就再按一下，它会轮着换下一个候选。名字长的时候，这个技巧能省不少事。

3 · 第二件事：dir，看当前有什么

进了一个文件夹，总得先看看里面有什么。dir 就是“列出当前文件夹里的东西”：

dir

敲完回车，你会看到一份清单：子文件夹的名字、文件的名字和大小。看到 hello.py 在清单里，才说明你现在这个文件夹里确实有这个文件，才能接着跑它。

macOS / Linux 上对应的命令是 ls，作用一模一样，只是名字不同：

# Windows：
dir

# macOS / Linux：
ls

你以后在教程里看到 ls，知道它就是 Windows 的 dir，别被名字唬住。

cd 和 dir 是一对搭档：先 dir 看看有什么，确认文件夹名字没敲错，再 cd 走进去；走进去之后再 dir，确认自己要的文件在不在。每次“文件找不到了”，先别怀疑人生，先 dir 一下——十有八九是你站错了文件夹。

4 · 第三件事：python xxx.py，运行一个 py 文件

写好的 Python 文件，要靠这一条命令跑起来：

python hello.py

python 是“请 Python 来干活”，hello.py 是“要干活的那个文件”。合起来就是：让 Python 把 hello.py 里的代码从头到尾执行一遍，执行结果直接打印在这个黑窗口里。

前四天你跑过的每一个练习文件，用的都是这条命令。把它们都再跑一遍，就当复习：

python hello.py
python debug_print.py
python file_io.py
python try_requests.py

每跑一个，看一眼输出还认不认识：hello.py 是第一天那句打印，debug_print.py 是第二天用 print 抓 bug 的练习，file_io.py 是第三天读写文件的练习，try_requests.py 是昨天装 requests 之后跑通的那个。四个都能跑起来，说明前四天的东西都在你手里。

python 还是 python3？Windows 上一般是 python，macOS / Linux 上常常是 python3。哪个命令能跑出版本号（python --version）就用哪个，不用纠结——昨天第 4 天也提过这一点。
报错说找不到文件的时候：先看报错第一行是不是 can't open file 之类的话。如果是，说明文件不在当前文件夹里：先 dir 看看清单，确认文件名有没有敲错、是不是站错了文件夹。文件名差一个字母、大小写不对，都会找不到。

5 · 第四件事：Ctrl+C，停下来

程序跑起来之后，有时候会卡住不动，或者陷入死循环，一直刷屏停不下来。这时候不用关窗口，也不用重启电脑，按住 Ctrl 再按一下 C：

# 程序卡住 / 刷屏不停的时候，按：
Ctrl + C

命令行会打断正在跑的程序，回到提示符，屏幕上一般会多一行 KeyboardInterrupt——那是 Python 在说“收到，你让我停我就停了”。这不是报错，是你主动叫停的正常结果。

什么时候会用到它？最常见的是两种：一种是写了死循环（比如 while True 里忘了写退出的条件），程序永远跑不完；另一种是昨天那种等网络的程序，网一直不通，程序就一直等着。两种情况都是按 Ctrl+C 停下来，改代码，再跑。

按一次没反应怎么办：有时候按一下停不下来，再按一次。还不行，就直接把黑窗口关掉重开一个——窗口关了，里面跑着的程序也就跟着停了。关窗口是最后的办法，平时 Ctrl+C 就够了。

6 · 四件事串起来：今天的小抄

把这四条命令连起来，就是以后每天都要走一遍的流程：

# 1. 走进练习文件夹
cd agent-practice

# 2. 看一眼里面有什么，确认文件在
dir

# 3. 跑起来
python hello.py

# 4. 卡住 / 刷屏不停的时候，Ctrl+C 停下来

就这么四行。以后每学一个新东西，流程都是这个：cd 进去、dir 看一眼、python 跑起来、出问题 Ctrl+C 停下来改。把这张小抄贴在手边，用上一个星期，就不用再查了。

阶段 0 收官：五天下来，你已经攒齐了整套地基——能读 Python 代码、会用 print 找 bug、会读写文件、会装包建虚拟环境、会在命令行里走路跑程序。下一阶段要调大模型 API，用的全是这些：写个 py 文件调接口，跑起来看返回，报错了读最后一行，改了再跑。地基齐了，就可以往上盖了。

7 · 容易踩的五个坑

  • 站错文件夹就跑程序：在 C:\Users\你的名字 里跑 python hello.py，但 hello.py 其实在 agent-practice 里，就会报找不到文件。先 cd 进去，再跑。
  • 文件夹名字有空格没加引号：cd my project 会报错，要写 cd "my project"。起名的时候直接避开空格最省事。
  • dir 和 ls 混着用：Windows 上是 dir，macOS / Linux 上是 ls，两个系统名字不一样，抄教程的时候先看自己是哪个系统。
  • python 后面忘了写文件名：只敲 python 会进 Python 自己的交互界面（出现 >>>），那不是跑文件。要跑文件一定是 python xxx.py，后面跟文件名。
  • 程序刷屏就慌着关窗口：先试 Ctrl+C，一次不行再按一次。关窗口是最后的办法，而且关了之后刚才的输出就看不到了。

测一测：读代码小题

下面四道题不用写代码，只要读，然后想一想会发生什么。点“显示答案”对一下。

第 1 题

C:\Users\小肥鱼> cd agent-practice
C:\Users\小肥鱼\agent-practice> dir

cd agent-practice 之后，提示符发生了什么变化？这时候敲 dir，列出来的是哪个文件夹里的东西？

提示符从 C:\Users\小肥鱼> 变成了 C:\Users\小肥鱼\agent-practice>，说明你已经走进 agent-practice 了。这时候 dir 列出来的就是 agent-practice 里面的东西，不再是上一级文件夹的。

第 2 题

C:\Users\小肥鱼> python hello.py
python: can't open file 'hello.py': [Errno 2] No such file or directory

报错说找不到 hello.py。最可能的原因是什么？第一步应该先敲什么命令确认？

最可能是你站错了文件夹：hello.py 在 agent-practice 里，而你现在还在 C:\Users\小肥鱼。第一步先敲 dir，看看清单里到底有没有 hello.py；没有的话，就 cd agent-practice 走进去再跑。

第 3 题

while True:
    print("还在跑")

这段代码跑起来会发生什么？要怎么让它停下来？停下来之后屏幕上会多出什么字？

会一直打印“还在跑”，刷屏停不下来，因为 while True 的条件永远是真的，没有退出的路。按 Ctrl+C 就能打断它，屏幕上会多一行 KeyboardInterrupt，意思是程序是被你主动叫停的，不算报错。

第 4 题

C:\Users\小肥鱼\agent-practice> cd ..
C:\Users\小肥鱼> dir

cd .. 之后你回到了哪里？这时候 dir 列出来的东西，和刚才在 agent-practice 里看到的一样吗？

回到了上一级文件夹 C:\Users\小肥鱼。这时候 dir 列出来的是这一级的东西——里面会有 agent-practice 这个文件夹本身，但不会再有 hello.py 那些文件，因为它们在下一级里面。

防屎山提醒

文件放得到处都是，本身就是一种屎山：同一个练习文件在桌面、下载文件夹、D 盘各有一份，改了这个忘了那个，最后不知道哪个才是最新的。从今天起养成习惯——一个项目一个文件夹，cd 进去再干活，文件只放在该放的地方。位置对了，代码才不容易乱。

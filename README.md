# Agent-learn

从零自学 AI Agent 的学习笔记。目标是做出能帮机械 / 工程软件干活的 Agent（比如用 SolidWorks API 做自动建模），而不是只停留在“会提示词”。

## 怎么用

- 打开 `index.html`，就是这个仓库的首页：六个阶段的目标、学习日志、每天的入口都在那里。
- 每天一个文件夹，名字里带日期，例如 `days/day-001-2026-11-14/`。每天只做当天那一页里的事。
- 每天 30–60 分钟；累了就做页面里标明的 10 分钟保底版，也算完成。周日休息，错过不补。
- 所有页面都是纯静态 HTML，不用装东西、不用联网，直接用浏览器打开就能看。

## 六个阶段

0. **捡回 Python 和命令行手感**——能读懂一段短代码，知道每一行在干什么，并能在命令行里跑起来。
1. **亲手调通一次大模型 API**——自己写代码发一句话给大模型，再把回答打印出来。
2. **手写工具调用和 Agent 循环（先不用框架）**——自己写出“想一想 → 用工具 → 看结果 → 再想一想”的循环。
3. **Git 五条命令 + 读报错 + 防屎山手艺**——只记最常用的五条命令，报错先看最后一行，每次只改一小步、随时能回滚。
4. **补 SolidWorks 操作与 API，让迷你 Agent 驱动建模**——先把 SolidWorks 操作补齐，再让迷你 Agent 通过 API 做一次简单建模。
5. **长期目标：内置 MCP / skill 的工程 Agent 框架**——做一个专门为工程软件准备的 Agent 框架，常用的 MCP 和 skill 内置好。
